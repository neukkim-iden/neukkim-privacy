Iden Growth 개인정보 처리방침

개발자: beomkyu · 시행일: 2026년 10월 22일

이 방침은 beomkyu가 제공하는 Iden Growth Android 앱(패키지명: com.growth.iden)과 이 개인정보 처리방침 웹페이지에 적용됩니다.

1. 앱에서 처리하는 정보와 목적

Iden Growth는 회원가입 없이 사용하는 목표·일상 기록 앱입니다. 목표 관리, 기록 표시, 주간 회고, 펫 성장 표시 및 설정 유지를 위해 다음 정보를 기기의 앱 저장공간에서 처리합니다.

  • 목표 이름·기준·일정·변경 이력, 날짜별 달성 상태, 입력한 수치와 메모
  • 주간 회고 내용·결과, 시간대 정보
  • 펫의 성장·이름·외형, 언어·모션 설정
  • 백업 생성 시각과 변경 취소에 필요한 정보

앱은 이러한 기록을 개발자 서버로 전송하지 않습니다. 개발자가 운영하는 계정 서버, 광고, 이용 분석 또는 오류 수집 기능은 없습니다.

2. 백업과 공유

사용자가 내보내기나 공유를 선택하면 백업 파일 또는 공유 이미지가 생성됩니다. 저장 위치와 공유 대상은 운영체제의 파일 선택·공유 화면에서 사용자가 결정합니다. 선택한 외부 앱·서비스로 전달된 파일에는 해당 서비스의 처리방침이 적용됩니다.

운영체제의 설정에 따라 앱 데이터가 시스템 백업이나 기기 이전에 포함될 수 있습니다. 이 사본의 보관과 삭제는 기기 및 백업 서비스의 설정에서 관리해야 합니다.

3. 외부 서비스

Android에서는 업데이트 가능 여부를 확인하기 위해 Google Play의 앱 업데이트 기능을 사용합니다. Google 문서에 따르면 이 과정에서 기기 메타데이터, 앱 버전, 설치된 모듈·애셋 팩 정보가 처리됩니다. 앱은 목표·메모·회고 내용을 이 기능에 전달하지 않습니다.

자세한 내용은 Google Play 앱 업데이트 데이터 안내와 Google 개인정보처리방침을 참고해 주세요.

이 개인정보 처리방침은 GitHub Pages 게시용 웹페이지입니다. GitHub Pages를 통해 방문하면 GitHub는 로그인 여부와 관계없이 보안을 위해 방문자의 IP 주소를 기록·보관합니다. 자세한 내용은 GitHub Pages 데이터 수집 안내와 GitHub 개인정보처리방침을 참고해 주세요.

이 페이지에는 자체 광고, 분석 도구, 추적 스크립트 또는 쿠키를 설치하지 않았습니다. 앱의 목표·메모·회고 기록은 이 웹페이지로 전송되지 않습니다.

4. 보관 기간과 삭제

앱에서 사용하는 기록은 삭제하거나 앱 데이터를 지울 때까지 기기의 앱 저장공간에 보관됩니다. 설정의 “이 기기의 모든 기록 삭제”는 현재 사용 중인 목표·실천·회고·펫을 초기화합니다.

별도로 보관한 이전 형식의 원본, 내보낸 백업, 공유한 이미지 및 운영체제 백업은 함께 삭제되지 않습니다. 공유 준비 중 생성한 임시 파일도 운영체제의 정리 또는 앱 제거 전까지 남을 수 있습니다.

기기의 앱 저장공간 전체를 비우려면 Android 설정의 앱 데이터 삭제 기능을 사용해 주세요. 별도로 저장·공유한 파일과 시스템 백업은 해당 저장 위치나 서비스에서 직접 삭제해야 합니다.

5. 정보 보호와 이용자 관리

일반 앱 기록에는 앱 자체의 별도 암호화를 적용하지 않으며, 운영체제의 앱별 저장공간을 사용합니다. 내보내는 .iden 백업 파일은 사용자가 정한 비밀번호를 바탕으로 AES-256-GCM 방식으로 암호화합니다. 앱은 백업 비밀번호를 저장하거나 복구하지 않습니다.

사용자는 앱에서 자신의 기록을 확인·수정·삭제하거나 내보낼 수 있습니다. 개발자는 기기의 기록을 서버에 보관하지 않으므로 이를 대신 조회·수정·복구할 수 없습니다. 기기 잠금과 운영체제 보안 기능을 사용하고, 백업 파일과 비밀번호를 안전하게 관리해 주세요.
